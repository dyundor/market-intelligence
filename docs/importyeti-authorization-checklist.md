# ImportYeti 付费 API 授权与计价确认清单

用途：在启用任何真实 ImportYeti paid operation / transport 之前，向 ImportYeti
取得书面确认。未获书面授权前不执行、不消耗 credits（见 AGENTS.md 付费政策与
DATA_SOURCE_ROADMAP.md）。

## 计价与额度

- [ ] 确认当前试用额度（credits）数量，以及是否计费 / 到期时间。
- [ ] 确认每次查询的实际计价方式（按条、按请求、按页、按字段）。
- [ ] 确认 Top 20 与 Top 50 查询是否同价，可否用 50 条结果截取 20 条。
- [ ] 确认是否支持按月 / 按 HS / 按收货人 / 按发货人筛选，各字段是否收费。
- [ ] 获取官方最新计价表，作为服务端 `estimate` / `maximumCost` 白名单依据。

## 数据与字段覆盖（美国海运试点 HS 848180）

- [ ] 返回字段是否包含：收货人（consignee/importer）、发货人（shipper）、提单号、装运/到港日期、HS Code、货重、数量、货柜数、货运金额。
- [ ] 确认字段缺失或为空时 API 返回什么（null / 省略 / 报错）。
- [ ] 确认是否提供估算运费，以及它是否可被标记为非申报货值。
- [ ] 确认数据覆盖起始时间与更新延迟（采集滞后多久可见最新月份）。

## 商业使用授权（逐项书面确认）

- [ ] 内部商业使用（自身分析、排序、定价）——是否允许。
- [ ] 对外 SaaS 展示（在公开站点向终端用户呈现企业名称/提单摘要）——是否允许。
- [ ] 缓存期限（把原始响应存入自有数据库可缓存多久）。
- [ ] CSV / Excel / 批量导出（供付费用户下载）——是否允许，是否需单独授权。
- [ ] 衍生分析（聚合、排名、估算模型）——是否允许。
- [ ] 联系人（电话/邮箱）是否随数据提供，使用是否受限。
- [ ] 合同/试用终止后的数据删除要求（保留期与删除义务）。

## 保存与备案

- [ ] 把官方答复原文（邮件/合同）存档到本目录或附出处 URL。
- [ ] 依据答复在 `DATA_SOURCE_ROADMAP.md` 更新授权状态。
- [ ] 依据计价表在服务端注册 operation 的 `estimate` / `maximumCost` 并单独审核 transport。
- [ ] 所有获批使用均记录到 `api_usage_requests` / `api_usage_log`。
